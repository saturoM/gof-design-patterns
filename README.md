# GoF Design Patterns (UA track)

Навчальний трек: **23 патерни Gang of Four** · теорія → короткі тести → коміт прогресу.

## Як вчимось

Спочатку біль — див. анкету **[CHOOSE.md](CHOOSE.md)** (який патерн обрати).

1. Сесія в чаті з асистентом (життя → IT → приклад у контексті)
2. Картка на 5 рядків + 1–3 тести
3. Якщо тести ок — коміт у цей репо
4. Практика в коді пізніше (напр. у `crypto-psp-sandbox`), не 23 окремі продукти

## Три полиці

| Група | Біль | Патерни |
|---|---|---|
| **Creational** | як створити | Singleton, Factory Method, Abstract Factory, Builder, Prototype |
| **Structural** | як скласти | Adapter, Bridge, Composite, Decorator, Facade, Flyweight, Proxy |
| **Behavioral** | як домовитись хто що робить | Chain of Responsibility, Command, Interpreter, Iterator, Mediator, Memento, Observer, State, Strategy, Template Method, Visitor |
