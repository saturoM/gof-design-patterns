# Factory Method · Creational №2

**Статус:** ✅ залік 2026-09-11

## Картка (5 рядків)

1. Ховаєш `new Concrete…` за методом-творцем.
2. Клієнт працює з **загальним** типом.
3. Плюс: легко додати новий вид без правок скрізь.
4. Мінус: зайвий шар, якщо вид один і простий.
5. Не плутати з **Builder** (складне збирання полів).

## Аналогії

- **Життя:** касир піцерії — ти просиш «піцу», кухня вирішує який саме клас страви готувати.
- **PSP:** `on_ramp` / `off_ramp` → фабрика повертає правильний вид інвойса; контролер не пише `new OnRampInvoice()`.

## Тести (пройдено)

1. Factory Method головним чином про? → **який тип створити**.
2. Комісії + FX snapshot? → ближче **Builder**, не Factory Method.

## Поліція болю

**Створити** — вирішуємо *який* клас народити, не розмазуючи `new` по клієнтах.
