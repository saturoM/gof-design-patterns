# Abstract Factory · Creational №3

**Статус:** ✅ залік 2026-09-11

## Картка (5 рядків)

1. Фабрика видає **сімейство** сумісних обʼєктів, не один.
2. Клиєнт вибрав «тему» (mock/live) — далі все з однієї сімʼї.
3. Плюс: важко змішати несумісне; зміна теми в одному місці.
4. Мінус: багато класів; новий член сімʼї → правки всіх фабрик.
5. FM = один продукт; AF = комплект.

## FM vs AF

| | Factory Method | Abstract Factory |
|---|---|---|
| Прохання | «створи on-ramp інвойс» | «створи весь mock-набір: rail+FX+signer» |
| Результат | один обʼєкт потрібного типу | набір сумісних обʼєктів |

### Життя

| Сфера | Factory Method | Abstract Factory |
|---|---|---|
| Будинок | вікно (дерево/пластик/енерго) | ремонт «сканди»: підлога+кухня+світло+фурнітура |
| Dota | пік одного героя під слот | турнірний пресет: пул+бани+HUD+коментарі |
| Спорт | ракетка (теніс/бадмінтон) | виїзний матч: форма+мʼяч+аптечка+транспорт під один спорт |
| Кіно | обʼєктив (50mm/wide) | знімальний день під кіно *або* рекламу (камера+звук+грим) |
| Кавʼярня | напій (еспресо/фільтр) | сніданковий сет однієї лінійки |

### Кодинг

| Домен | Factory Method | Abstract Factory |
|---|---|---|
| Маркетплейс | `Listing` товар/послуга/аукціон | ринок UA: currency+VAT+доставка+PSP |
| Fintech/PSP | on-ramp *або* off-ramp invoice | sandbox: mock rail+FX+signer (або все live) |
| Casino | гра slots/roulette | ліцензійний стек: wallet+RG+RNG однієї юрисдикції |
