# Abstract Factory · Creational №3

**Статус:** ✅ залік 2026-09-11

## Картка (5 рядків)

1. Фабрика видає **сімейство** сумісних обʼєктів, не один.
2. Клиєнт вибрав «тему» (mock/live) — далі все з однієї сімʼї.
3. Плюс: важко змішати несумісне; зміна теми в одному місці.
4. Мінус: багато класів; новий член сімʼї → правки всіх фабрик.
5. FM = один продукт; AF = комплект.

## FM vs AF

| | Factory Method | Abstract Factory |
|---|---|---|
| Прохання | «створи on-ramp інвойс» | «створи весь mock-набір: rail+FX+signer» |
| Результат | один обʼєкт потрібного типу | набір сумісних обʼєктів |

## Аналогії

**Життя**

| Світ | FM | AF |
|---|---|---|
| Будинок | двері вхідні (вид) | обставить квартиру в одному стилі |
| Dota | герой Support | турнірний пресет (герой+ітеми+HUD) |
| Спорт | мʼяч для гри | екіпіровка під один вид спорту |
| Кіно | тип кадру | пакет продакшену під один формат |

**Кодинг**

| Домен | FM | AF |
|---|---|---|
| Маркетплейс | тип Order | регіон-набір: tax+shipping+pay |
| Fintech/PSP | on-ramp / off-ramp invoice | mock **або** live стек |
| Casino | слот / рулетка | юрисдикція: RNG+KYC+wallet rules |

## Тести (пройдено)

1. Турнірний пресет у Dota → **Abstract Factory**
2. «Створи on-ramp інвойс» → **Factory Method**

## Поліція болю

**Створити** — народжуємо сумісний комплект під одну «тему».
