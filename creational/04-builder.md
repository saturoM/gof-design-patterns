# Builder · Creational №4

**Статус:** ✅ залік 2026-09-11

## Картка (5 рядків)

1. Покрокова збірка **одного** складного обʼєкта.
2. Як бургер / інвойс з FX + fees.
3. Плюс: без монстр-конструктора; контроль «готово» через `build()`.
4. Мінус: зайвий код, якщо полів мало.
5. AF = сімʼя сумісних речей · Builder = рецепт **однієї** речі.

## Уточнення (важливо)

- **AF** видає окремі готові обʼєкти однієї теми (їх можна тримати як самостійні сервіси; головне — не мішати теми).
- **Builder** збирає один агрегат з кроків/частин; клієнту в кінці — готовий продукт, не «команда рівноправних фабрик».

## Приклади

**Життя:** ремонт кроками · білд у Dota · монтаж у кіно · кастом-напій  
**Кодинг:** listing publish · invoice FX/fees · casino bonus offer  

## AF vs Builder (пари)

| Сфера | Abstract Factory | Builder |
|---|---|---|
| Будинок | стиль «лофт» (комплект) | один гарнітур по кроках |
| Dota | турнірний пресет | білд одного героя |
| Fintech | mock-стек rail+FX+signer | один інвойс з FX/fees |
| Casino | ліцензійний стек | один бонусний офер |
