# Prototype · Creational №5

**Статус:** ✅ залік 2026-09-11

## Картка (5 рядків)

1. Клон зразка + підкрутка.
2. Дешевше за збірку з нуля, коли новий ≈ старий.
3. Плюс: швидкість, менше boilerplate збірки.
4. Мінус: deep copy; поганий шаблон розмножує помилки.
5. vs Builder: є донор → Prototype; з нуля по кроках → Builder.

## Prototype vs Builder

| | Prototype | Builder |
|---|---|---|
| Старт | готовий зразок | з нуля |
| Дія | клон + tweak | кроки → `build()` |

**Життя:** типовий проєкт будинку · білд з гіда Dota · шаблон таймлайну · «як звичайний напій, але…»  
**Кодинг:** дублікат listing · шаблонний інвойс + amount · клон бонусного офера
