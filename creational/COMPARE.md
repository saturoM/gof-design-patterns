# Creational — вся картина (порівняння)

## Що питає кожен

| Патерн | Головне питання | Результат |
|---|---|---|
| Singleton | *Скільки* екземплярів на процес? | 1 службовий обʼєкт |
| Factory Method | *Який тип* одного продукту? | 1 обʼєкт потрібного класу |
| Abstract Factory | *Яка тема* комплекту? | Набір сумісних обʼєктів |
| Builder | *Як зібрати* один складний з нуля? | 1 зібраний обʼєкт |
| Prototype | *Від чого клонувати*? | 1 копія шаблону + tweak |

## Плюси / мінуси

| Патерн | + | − |
|---|---|---|
| Singleton | спільна точка процесу | глобалка; тести; не на весь світ |
| Factory Method | новий тип локально | overkill якщо тип один |
| Abstract Factory | не змішаєш теми | багато класів; новий член сімʼї |
| Builder | кроки; контроль `build()` | зайве для простих полів |
| Prototype | швидко якщо є донор | deep copy; токсичний шаблон |

## Одна сітка: fintech / e-commerce / gambling

| Ситуація | Fintech | E-commerce | Gambling | Патерн |
|---|---|---|---|---|
| Один службовий на процес | логер api | config процесу | логер gateway | Singleton |
| Вибрати вид одного | on/off-ramp invoice | listing товар/аукціон | slots/roulette | Factory Method |
| Комплект однієї теми | mock vs live стек | UA vs EU стек | ліцензія A vs B | Abstract Factory |
| Зібрати складне з нуля | invoice+FX+fees | listing wizard | bonus offer | Builder |
| Зробити схоже на існуюче | шаблон invoice+amount | схожий listing | клон бонусу | Prototype |

## Дерево вибору

1. Службовий один на процес? → **Singleton**
2. Є шаблон і мала різниця? → **Prototype**
3. Багато кроків одного обʼєкта з нуля? → **Builder**
4. Потрібен комплект однієї теми? → **Abstract Factory**
5. Лише який клас одного продукту? → **Factory Method**
6. Нічого з цього → **без патерна**

## Сусіди

| Пара | Розвідник |
|---|---|
| Singleton vs БД | Переживе рестарт і другий інстанс? |
| FM vs AF | Один продукт чи комплект? |
| Builder vs Prototype | З нуля чи є донор? |
| AF vs Builder | Сімʼя сервісів чи один агрегат? |
