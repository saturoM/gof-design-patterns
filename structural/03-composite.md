# Composite · Structural №3

**Статус:** ✅ залік 2026-09-12

## Проблема

Дерево: лист і гілка. Клиєнт хоче ту саму дію для обох, інакше код повний `if/instanceof` і ручної рекурсії.

## Рішення

Спільний інтерфейс `Component`. Лист реалізує сам; гілка делегує дітям (діти теж `Component`, можна вкладено).

## Картка

1. Лист і гілка — один інтерфейс.
2. Клиєнт кличе однаково (`size()`, `total()`).
3. Гілка = контейнер дітей-компонентів.
4. + менше `instanceof`, вкладеність природна.
5. − товстий інтерфейс; не все варто уніфікувати.

## Приклади

| Домен | Лист | Гілка |
|---|---|---|
| Файли | файл | папка |
| Fintech | payment/invoice | batch / pack |
| E-commerce | SKU | bundle / category |
| Gambling | bet | express / parlеy |
| Dota | гравець | команда |
