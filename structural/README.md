# Structural

**Формула полиці:** як **підключити нове до старого** за формою звʼязку — не переписуючи старе.

Creational питав *як народити*. Structural — *як скласти / стикувати / обгорнути*.

## 7 патернів

| # | Патерн | Одним рядком |
|---|---|---|
| 1 | Adapter | чужий інтерфейс під наш (перехідник) |
| 2 | Bridge | відокремити абстракцію від реалізації |
| 3 | Composite | дерево однакових вузлів |
| 4 | Decorator | додати поведінку обгортками |
| 5 | Facade | простий вхід до складної підсистеми |
| 6 | Flyweight | багато обʼєктів ділять спільний стан |
| 7 | Proxy | заступник (доступ / лінь / лог) |

## Грубий компас

1. Не стикується API? → Adapter  
2. Простий вхід до купи модулів? → Facade  
3. Додати поведінку без зміни класу? → Decorator  
4. Контроль/кеш перед реальним обʼєктом? → Proxy  
5. Частина і ціле однаково? → Composite  

Картки зʼявляться тут після заліку кожного патерна.
