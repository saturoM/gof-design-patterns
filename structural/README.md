# Structural

**Формула полиці:** як **підключити нове до старого** за формою звʼязку — не переписуючи старе.

Creational питав *як народити*. Structural — *як скласти / стикувати / обгорнути*.

## 7 патернів

| # | Патерн | Файл / рядок |

| 1 | Adapter | [01-adapter.md](01-adapter.md) — чужий інтерфейс під наш |
| 2 | Bridge | [02-bridge.md](02-bridge.md) — дві осі через посилання |

## Грубий компас

1. Не стикується API? → Adapter  
2. Простий вхід до купи модулів? → Facade  
3. Додати поведінку без зміни класу? → Decorator  
4. Контроль/кеш перед реальним обʼєктом? → Proxy  
5. Частина і ціле однаково? → Composite
